# CODM English Patch v0.3 — final release, discontinued

## Important risk notice

This unofficial patch modifies CODM game files. Activision's public COD Mobile security policy includes enforcement for unauthorized software that modifies game data and for reverse engineering game data. A text-only patch is not guaranteed to be safe; anti-cheat action or account sanctions, including a ban, are possible. The project has no publisher authorization. For the lowest account risk, use an unmodified official installation. The Chinese edition may have separate publisher terms.

This is the last release. The project is discontinued; no future updates, compatibility fixes, or support are planned.

## v0.3 changes

- Updates the tested lobby and settings language tables.
- Aligns eligible shop/item text with paired English or identified Global wording while preserving 47 unmatched or China-specific entries in Chinese.
- Corrects 38 day/day-count phrases that had rendered as “Jesus” across 74 main-catalog records.
- Keeps backups-before-write and supports the exact earlier package hashes recorded in the manifest.

## Scope and limits

The user reported that the final clone worked. This is not a guarantee for another client build or future updates. The patch does not cover every server-delivered label, all event panels, or text embedded in images/video. Global wording parity is not certified for every string. One China-only creator display name and an unidentified map-introduction label remain unresolved.

## Install and restore

Read the [Portuguese guide](TUTORIAL-PT-BR.md) and the warning in the README before using the patch. The game client is not included. The safest option for normal online play is an unmodified official installation.
